# 더치페이 정산 계산기

## 대상 사용자

- 친구들과 식사하고 나서 결제 금액을 나눠 내야 하는 나. 모임 자리에서 휴대폰으로 바로 계산합니다.

## 사용 목적

- 총 결제 금액과 인원수를 넣으면 1인당 내야 할 금액을 바로 알려 줘서, 계산기를 따로 켜지 않고 정산합니다.

## 화면 구성과 동작

- 맨 위에 '더치페이 계산기' 제목이 있습니다.
- '총 금액(원)'과 '인원수(명)' 입력칸이 있습니다.
- '100원 단위로 올림' 체크박스가 있습니다. 켜면 1인당 금액을 100원 단위로 올립니다.
- '계산' 버튼을 누르면 결과가 나옵니다. 결과는 '1인당 12,500원'과 '총 걷는 금액 50,000원 · 남는 금액 0원' 줄입니다.
- 올림을 켜면 걷는 금액이 총 금액보다 많아질 수 있고, 그 차이를 '남는 금액'으로 보여 줍니다.
- 입력이 올바르지 않으면 결과를 지우고 이유를 알려 주는 안내 문구를 보여 줍니다.
- '다시 입력' 버튼을 누르면 입력칸, 체크박스, 결과가 처음 상태로 돌아갑니다.

## 필요한 자료

- 총 금액(원)과 인원수(명)는 사용자가 직접 입력합니다. 미리 들어 있는 자료는 없습니다.

## 완료 기준

- 총 금액 50,000원, 인원 4명, 올림 끔으로 계산하면 '1인당 12,500원'이 나옵니다.
- 총 금액 10,000원, 인원 3명, 올림 끔으로 계산하면 '1인당 3,334원'(원 단위 올림)이 나옵니다.
- 총 금액 10,000원, 인원 3명, 올림 켬으로 계산하면 '1인당 3,400원', '남는 금액 200원'이 나옵니다.
- 총 금액이 비었거나 0 이하이거나 소수이면, 인원수가 비었거나 1 미만이거나 소수이면 결과 없이 안내 문구가 나옵니다. (금액은 원 단위 정수만 받습니다)
- '다시 입력'을 누르면 입력칸과 결과가 모두 비워집니다.
- 휴대폰 화면에서 가로로 밀지 않고 입력과 버튼을 쓸 수 있습니다.
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열립니다.

## 추가 기능

- 사람마다 먹은 금액이 다를 때 따로 나누는 기능
- 계산 결과를 메시지로 복사하는 기능

## 한계 및 비목표

1. 모든 사람이 같은 금액을 내는 균등 분할만 합니다.
2. 계산 기록을 저장하지 않습니다. 창을 닫으면 사라집니다.
3. 송금이나 결제는 하지 않습니다. 금액을 알려 주기만 합니다.

## 검증 방법

- 총 금액 ÷ 인원수를 손이나 계산기로 계산해 원 단위로 올린 값과 화면의 1인당 금액을 비교합니다.
- '1인당 금액 × 인원수 − 총 금액'을 계산해 화면의 남는 금액과 같은지 확인합니다.
