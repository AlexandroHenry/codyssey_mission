# 민수 님의 영화 티어리스트 피드백

> 본 것 · 기준 · 제안 순서로 적었습니다. 코드를 읽고 판단했고, 직접 열어 눌러 본 것은 아닙니다.

## 잘된 점

- 칸마다 색이 달라서 S·A·B·C 중 어디에 놓였는지 한눈에 구분됩니다. (`tier-S`~`tier-C` 색상)
- 위쪽의 'N편 중 M편 나눔' 표시로 남은 영화를 바로 알 수 있습니다.
- 카드를 끌 때 놓을 칸이 강조되어(`is-over`) 어디로 들어가는지 미리 보입니다.
- '처음으로'를 누르면 직접 추가한 영화까지 지워지고 처음 8편만 남아 기획서와 같습니다.

## 고치면 좋을 점

1. **휴대폰 화면에서 잘립니다.**
   - 본 것: `.page`가 `width: 960px`로 고정이고 `@media`가 없습니다. `body`가 `overflow-x: hidden`이라 넘친 부분은 스크롤도 안 됩니다.
   - 기준: 완성 기준 '화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.'
   - 제안: `width: min(100% - 32px, 960px)`로 바꾸고, 좁은 화면에서는 등급 글자 칸 폭과 글자 크기를 줄입니다.
2. **다시 열면 배치가 사라집니다.**
   - 본 것: `localStorage`를 쓰는 코드가 없습니다.
   - 기준: 완성 기준 '같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.'
   - 제안: 옮기거나 추가할 때마다 상태를 저장하고, 시작할 때 읽어 옵니다.
3. **빈 제목으로 카드가 생깁니다.**
   - 본 것: 아무것도 쓰지 않거나 공백만 넣고 '추가'를 눌러도 글자 없는 카드가 생깁니다.
   - 기준: 기획서에는 없지만 제목 없는 카드는 쓸모가 없고 AI 검토도 짚었습니다.
   - 제안: `trim()` 결과가 비면 추가하지 않고 '영화 제목을 입력해 주세요.'를 보여 줍니다.
4. **같은 제목이 두 번 들어갑니다.**
   - 본 것: 이미 있는 제목을 추가해도 막지 않습니다.
   - 제안: 같은 제목이면 안내 문구를 보여 주고 추가하지 않습니다.

## 참고 (AI 검토 내용 중 맞지 않은 것)

- AI는 "'처음으로'가 직접 추가한 영화를 지우지 않는다"고 했지만, 코드는 `state = fresh()`로 8편만 새로 만들어서 추가한 영화도 지웁니다. 고칠 필요가 없습니다.

## 동료 의견 중 바로 반영하지 않기를 권하는 것

- 포스터 사진: '외부 파일 없이 HTML 한 장' 기준과 충돌합니다.
- C칸 삭제: 기획서가 S·A·B·C로 정해 둔 것이라 기획서를 바꿀 때 함께 결정해야 합니다.
