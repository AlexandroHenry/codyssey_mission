# codyssey_mission

코디세이 입학연수 미션 결과물 모음입니다. 미션마다 폴더(`mission_001/`, `mission_002/`)가 있고, 그 안에 세부 미션 폴더(`1-1`, `2-1` …)가 있습니다.
미션별 작업은 `mission_미션번호` 브랜치에서 하고, 끝나면 `main`에 머지합니다.

## mission_001 - 영화 티어리스트

영화 8편(기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리)을 S·A·B·C 등급으로 나누는 HTML 한 장을 AI와 함께 만들고, 고치고, 피드백을 주고받는 미션입니다.

| 폴더 | 요구한 것 | 결과물 |
|---|---|---|
| `1-1` | '영화 티어리스트를 만들고 싶다'는 아이디어를 AI의 질문에 답하며 기획서로 만들고, 그 기획서로 HTML 첫 버전을 만든다. 기획서와 다르게 동작하는 부분은 고친다. | `기획서.md`, `영화_티어리스트.html` |
| `1-2` | 일부 영화만 옮겨지지 않는 `영화_수정전.html`의 오류를 직접 재현해 원인을 좁히고, 본 대로 AI에게 물어 그 문제만 고친다. 원본은 덮어쓰지 않고 `영화_수정1.html`로 저장한다. | `영화_수정전.html`, `영화_수정1.html`, `미션2_기록.md` |
| `1-3` | 민수 님의 기획서·HTML과 받은 피드백(AI 검토, 동료 의견)을 기획서의 완성 기준대로 직접 확인한다. 의견마다 반영·보류·확인 요청을 정하고, 본 것·기준·제안 순서로 피드백을 쓴다. | `미션3_기록.md`, `피드백.md` |
| `1-4` | 원본을 그대로 두고, 더할 기능의 완성 기준을 기획서에 먼저 쓴 뒤 AI에게 기능을 추가하게 한다. 새 기능이 틀리면 새 이름으로 고쳐 저장하고, 원래 기능이 망가지면 원본으로 돌아가 다시 요청한다. | `기획서.md`, `영화_원본.html`, `영화_기능추가.html`, `미션4_기록.md` |

이 미션에서 이어지는 습관: 원본을 덮어쓰지 않고 버전 이름을 남기기, 무엇을 바꿨고 왜 바꿨는지 드러나는 커밋 메시지 쓰기, 완성 기준을 직접 눌러 보며 확인하기.

## mission_002 - 더치페이 계산기

기획서 양식에 맞춰 페이지를 기획하고, AI로 만들어 테스트하며 고치고, 그 과정을 기록하는 미션입니다. 이 레포의 주제는 '더치페이 계산기'(총 금액 ÷ 인원수, 100원 단위 올림 선택)입니다.

| 폴더 | 요구한 것 | 결과물 |
|---|---|---|
| `2-1` | 양식(대상 사용자, 사용 목적, 화면 구성과 동작, 필요한 자료, 완료 기준, 추가 기능, 한계 및 비목표, 검증 방법)에 맞춰 기획서를 쓴다. | `기획서.md` |
| `2-2` | 같은 기획서로 두 AI에게 HTML을 만들게 해 비교하고 하나를 고른다. 테스트(좁은 화면·빈칸 입력 등 조건 포함)와 수정 기록, 사용자 테스트를 `제작검증기록.md` 양식에 적는다. | `더치페이_계산기.html`(첫 버전), `제작검증기록.md` |
| `2-3` | 발견한 문제를 고치고(수정 전 결과, AI에게 한 요청, 수정 후 결과, 이유), 기획서의 한계·검증 방법을 최종 HTML에 맞게 고친다. | `기획서.md`, `더치페이_계산기.html`(수정본), `제작검증기록.md` |

### 지금 비어 있는 부분

- 2-2의 두 번째 AI(AI B) 비교와 사용자 테스트는 실제로 하지 않아 '미실시'로 표시했습니다.
- 휴대폰 등 좁은 화면 확인은 직접 열어서 해야 합니다.
- 미션 1·2의 확인 내용은 대부분 코드를 읽거나 Node.js로 돌려서 얻은 것이며 브라우저에서 눌러 본 결과가 아닙니다. 각 기록 파일 맨 위에 적어 두었습니다.
